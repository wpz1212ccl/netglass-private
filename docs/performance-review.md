## 5. 决策记录

1. **DC 时暂停外网探针**：已实现；采样保持 1 Hz。
2. **260 ms 前台轮询**：保留，不改 WinEvent。零行为风险，成本主要在电源层面而非 CPU。
3. **WebView2 内存地板**：不做处理。不切换 native / 不改渲染架构，私用内存降不到 100 MB 以下。

## 6. 复跑方式

```powershell
powershell -ExecutionPolicy Bypass -File "docs\perf-check.ps1" -Minutes 60 -IntervalSec 30
```

`perf-check.ps1` 的 A2（<0.5% 单核）与 A3（<60 MB）是按 native 设定的阈值，Tauri 版必然 FAIL，不能当作回归信号。
